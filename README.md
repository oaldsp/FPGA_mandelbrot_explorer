# FPGA_mandelbrot_explorer
O FPGA Mandelbrot Explorer é uma implementação em hardware do renderizador do Conjunto de Mandelbrot desenvolvida em VHDL. O sistema permite a visualização interativa do fractal por meio de movimentação horizontal e vertical, além de operações de zoom em tempo real. A arquitetura utiliza múltiplos núcleos de processamento executando em paralelo, um escalonador dinâmico de linhas para balanceamento de carga, mapeamento de cores e dupla bufferização (double buffering) para atualização suave da imagem. Os resultados são exibidos em um monitor por meio de uma interface VGA.
